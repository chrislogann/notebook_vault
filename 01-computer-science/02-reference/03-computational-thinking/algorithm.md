# Algorithm

## Overview
> A highly structured plan consisting of a set of step-by-step instructions designed to resolve a specific problem.

## Core Concepts
- **Required Elements:** Must contain a clear starting point, unambiguous instructions in between, and a clear finishing point.
- **Representation:** Typically mapped out using flowcharts (visual diagrams) or pseudocode (plain English logic) prior to actual coding.
- **Garbage In, Garbage Out:** Computers cannot think for themselves; they will blindly execute flawed algorithms, resulting in inevitably incorrect outputs.
