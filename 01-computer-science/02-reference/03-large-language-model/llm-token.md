# Token

## Overview
> A token is the fundamental atomic numerical unit of character or sub-word text processed and generated by transformer-based language models.

## Core Concepts
- Raw text is segmented into tokens and mapped to unique integer IDs to serve as numerical inputs for machine learning matrices.
- Tokens pass through embedding layers to transform discrete integer IDs into dense semantic vectors for self-attention calculations.
- Act as the core unit measuring computational complexity, context window capacity, and commercial API consumption costs.
