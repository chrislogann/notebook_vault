# Hugging Face

## Overview
> Hugging Face is the industry-standard collaborative platform and developer ecosystem that democratizes access to pre-trained AI model weights and code libraries.

## Core Concepts
- The Model Hub and Datasets Library standardize access to pre-trained weights and benchmark datasets across ML frameworks.
- The `transformers` Python library provides standardized APIs for loading, fine-tuning, and deploying diverse Transformer architectures.
- Spaces and managed Inference Endpoints lower the barrier to entry for hosting and testing prototype AI applications.
