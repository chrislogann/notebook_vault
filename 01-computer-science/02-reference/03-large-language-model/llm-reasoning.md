# Llm Reasoning

## Overview
> LLM reasoning refers to the model's capacity to perform complex, multi-step logical deductions or solve problems that require simulated human cognitive processes. It involves generating coherent chains of thought rather than simply recalling factual data points.

## Core Concepts
- **Chain-of-Thought (CoT) Prompting:** Guiding the LLM by prompting it to show its intermediate steps and reasoning process, significantly improving performance on complex tasks like math or symbolic logic.
- **Self-Correction / Reflection:** The ability to analyze and critique its own initial output against a set of criteria, iteratively refining the answer for increased accuracy and depth.
- **Retrieval Augmented Generation (RAG):** Enhancing reasoning by grounding the model's internal knowledge base with external, verified, real-time documentation or databases before generating a final answer, minimizing hallucination.
