# License

## Overview
> Model licensing defines the legal parameters, commercial restrictions, and usage agreements governing the distribution and deployment of LLM weights and code.

## Core Concepts
- Open-weights licenses permit local inspection and execution but may impose commercial thresholds or usage restrictions.
- Open-source licenses grant full, unconstrained freedom to modify, fine-tune, and commercialize model architectures.
- Licensing structures directly dictate enterprise deployment strategies, balancing risk governance with operational autonomy.
