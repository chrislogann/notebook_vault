# Benchmark

## Overview
> Benchmarks serve as standardized metric frameworks necessary to evaluate, validate, and compare LLM capabilities across knowledge, logic, and safety domains.

## Core Concepts
- Knowledge benchmarks (e.g., MMLU) test broad domain recall, while logic benchmarks (e.g., GSM8K) measure multi-step chain-of-thought reasoning.
- Systemic evaluation frameworks (e.g., HELM) assess holistic parameters including fairness, efficiency, and robustness against jailbreaks.
- Primary evaluation failure modes include benchmark data contamination and high sensitivity to prompt engineering variations.
