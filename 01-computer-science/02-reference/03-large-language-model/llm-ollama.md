# Ollama

## Overview
> Ollama is an open-source inference runtime designed to simplify running, managing, and serving quantized LLMs locally on consumer hardware.

## Core Concepts
- Standardizes local model execution by bundling dependency management and model configuration into simple terminal commands.
- Automatically manages quantized weight formats to enable execution of large models within constrained system RAM/VRAM pools.
- Exposes a standardized local REST API endpoint allowing private, offline integrations for edge devices and localized agents.
