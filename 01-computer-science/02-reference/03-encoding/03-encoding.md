# 03 Encoding

## Overview
> Encoding in computing is fundamentally a process of translation, referring to the systematic conversion of information from one defined format into another standard, transmittable representation.

## Core Concepts
- Character Encoding (e.g., UTF-8) maps abstract human characters onto numerical digital values for global text consistency.
- Data and Signal Encoding (e.g., Base64, ECC) converts raw binary streams into formats robust against transmission errors or physical medium incompatibilities.
- Media Encoding (e.g., H.264, MP3) compresses complex continuous signals into digital formats using psychoacoustic and psychovisual codecs.
