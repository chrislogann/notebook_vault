# 03 Machine Learning

## Overview
> Machine Learning (ML) is a subset of Artificial Intelligence that enables systems to identify patterns and make decisions from data without explicit rule-based programming.

## Core Concepts
- **Taxonomy of Learning:** Algorithms fall under Supervised Learning (labeled classification/regression), Unsupervised Learning (unlabeled clustering/dimensionality reduction), and Reinforcement Learning (agent reward optimization).
- **Deep Learning Integration:** Utilizes multi-layered neural networks (e.g., CNNs for computer vision, Transformers for sequence processing) to automatically perform feature extraction from raw datasets.
- **Systemic Challenges:** Models are constrained by training data quality ("garbage in, garbage out"), suffer from black-box interpretability issues, and incur massive computational resource costs.
- **Emerging Frontiers:** Development focuses on Edge AI execution, multimodal model architecture, and establishing causal reasoning beyond statistical correlation.
