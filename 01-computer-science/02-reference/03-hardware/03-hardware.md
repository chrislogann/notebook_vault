# 03 Hardware

## Overview
> A comprehensive categorization of the physical components that constitute a modern computing system, interacting via structured architecture and specialized functional units.

## Core Concepts
- The Central Processing Unit (CPU) acts as the system brain, managing data flow and executing general instructions.
- The Graphics Processing Unit (GPU) handles massive parallel computations and specialized vector processing.
- Random Access Memory (RAM) provides ultra-fast, volatile storage for active processes, acting as a bridge between the CPU and long-term storage.
- The Motherboard serves as the central nervous system connecting all discrete components and regulating I/O bottlenecks.
