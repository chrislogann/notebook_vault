# Ram

## Overview
> Random Access Memory (RAM) is volatile, high-speed working memory that temporarily holds active data and instructions for immediate execution by the CPU.

## Core Concepts
- Modern RAM operates dynamically (DRAM), requiring constant electrical power and periodic refreshing from the memory controller to prevent data loss.
- Performance limits are determined by a balance of total Capacity (GB), Frequency/Data Rate (MT/s), and Latency timings (CL) affecting the delay before data can be read.
- It acts as an operational bridge within the memory hierarchy, situated between ultra-fast integrated CPU cache and significantly slower non-volatile storage drives.
