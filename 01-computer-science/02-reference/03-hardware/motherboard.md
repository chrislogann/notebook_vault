# Motherboard

## Overview
> The motherboard is the primary printed circuit board (PCB) that acts as the central communication backbone, data arbitrator, and power distributor for all discrete computer components.

## Core Concepts
- It regulates system bottlenecks by managing high-speed data transfers across standardized buses, including PCI Express (PCIe) and the DDR Memory Bus.
- The Chipset acts as the traffic controller for secondary communication pathways (SATA, USB, network interfaces), while the CPU socket defines physical and electrical processor compatibility.
- The Voltage Regulator Module (VRM) is critical for converting system power into highly precise, stable voltages required by the CPU to prevent thermal throttling and instability.
