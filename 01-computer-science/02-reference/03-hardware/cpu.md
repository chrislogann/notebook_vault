# Cpu

## Overview
> The Central Processing Unit (CPU) is the computational engine of modern digital computing systems that executes instructions via the Fetch-Decode-Execute cycle.

## Core Concepts
- Key internal components include the Arithmetic Logic Unit (ALU) for calculations, the Control Unit (CU) for directing data flow, and ultra-fast integrated Registers.
- Performance is multi-dimensional and dictated by clock speed (GHz), core count, cache memory efficiency, and thread management capabilities.
- Architectures are divided into Instruction Set Architectures (ISA), primarily contrasting complex instruction sets (x86-64) with reduced instruction sets (ARM).
