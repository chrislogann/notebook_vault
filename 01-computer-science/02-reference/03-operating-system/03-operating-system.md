# 03 Operating System

## Overview
> An operating system (OS) is a foundational collection of software that acts as an intermediary between computer hardware and users, managing essential system resources and providing common services for application execution.

## Core Concepts
- **Resource Allocation:** The OS manages and coordinates critical hardware resources, including CPU task scheduling, physical memory (RAM), and virtual memory spaces.
- **Hardware Abstraction:** It provides high-level abstractions—such as processes, threads, files, and network sockets—simplifying complex hardware interactions for software applications.
- **Core Architecture:** The kernel acts as the central component bridging software programs and physical hardware, supported by input/output device drivers, file system managers, and security enforcement mechanisms.
