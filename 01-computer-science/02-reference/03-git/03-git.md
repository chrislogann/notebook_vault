# 03 Git

## Overview
> Git is a distributed version control system designed to track changes in source code during software development and enable parallel collaboration.

## Core Concepts
- **Repositories & Commits:** A repository stores project files and their complete change history, while commits act as unique, time-stamped snapshots of the codebase.
- **Branching & Staging:** Branching allows developers to diverge from the main codebase to isolate features or fixes, utilizing an intermediate staging area to review changes before committing.
- **Distributed Architecture:** Every collaborator maintains a full local clone of the repository, enabling offline work, high performance, and rapid experimentation or rollback.
