# 03 Network

## Overview
> Computer networking encompasses the architecture, protocols, and infrastructure that enable interconnected computational nodes to exchange data and share resources reliably.

## Core Concepts
- **Protocol Stacks & Routing:** Communication is organized across layered network models (e.g., OSI and TCP/IP stacks) that govern data encapsulation, packet routing, and transport-layer reliability.
- **DNS & Name Resolution:** Domain Name System infrastructure translates human-readable domain names into IP addresses, serving as a gateway for routing traffic and implementing domain-level security filtering.
- **Encrypted Tunnels & Mesh Access:** Secure protocols establish encrypted virtual private networks (VPNs) over public media to interconnect remote nodes and control private subnet access.
