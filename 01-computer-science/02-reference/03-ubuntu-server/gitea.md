# Gitea

## Overview
> Gitea is a lightweight, self-hosted Git software service written in Go, providing complete control over source code repositories with minimal resource footprint.

## Core Concepts
- **Resource Efficiency:** Consumes minimal memory and processing power, ideal for hosting private code on low-power hardware or containerized environments.
- **Feature Set:** Includes repository management, issue tracking, Kanban boards, Gitea Actions CI/CD, and organization access control.
- **Deployment Flexibility:** Easily deployed via Docker or binary executables, supported by backend databases like SQLite, PostgreSQL, or MariaDB.
