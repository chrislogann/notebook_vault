# Speedtest Cli

## Overview
> Speedtest CLI is a command-line utility by Ookla designed to test network latency, download speed, and upload bandwidth directly from a headless terminal.

## Core Concepts
- **Headless Execution:** Enables accurate WAN throughput testing over SSH sessions without requiring a graphical desktop environment or web browser.
- **Automation and Export:** Outputs data in structured JSON, CSV, or TSV formats, making it optimal for automated cron logging and ISP performance tracking.
- **Direct Hardware Testing:** Eliminates local Wi-Fi and intermediary router overhead to record a clean measurement of external internet connectivity.
