# Docker

## Overview
> Docker is a containerization platform that packages software applications along with their code, libraries, and dependencies into lightweight, isolated execution environments.

## Core Concepts
- **Dependency Isolation:** Eliminates host dependency conflicts by executing every application inside its own isolated filesystem.
- **Key Terminology:** Consists of Images (read-only blueprints), Containers (running instances), Docker Engine (daemon), and Docker Compose (multi-container orchestration).
- **Infrastructure Cleanliness:** Prevents host system clutter and enables rapid testing, seamless version rollbacks, and clean application removal.
