# Vault Map

> **System Directive Reminder:** This map outlines the strict 4-tier hierarchical taxonomy of `notebook-vault`. All new notes must be placed within their corresponding `[domain]/[class]/[subject]/` folder. Do NOT create sub-directories inside subject folders.

## System & Utility Directories
*   `_script/`: Contains workspace automation scripts (Python, shell, Dockerfiles).
    *   `/import-template/`: Scripting for parsing and migrating bulk markdown templates.
    *   `/create-content/`: Tooling for Ollama-based local LLM note synthesis.
    *   `/import-book/`: Scripting for parsing EPUB/PDF files into obsidian literature notes.
    *   `/backlink-export/`: Tooling for exporting markdown files with all linked dependencies.
*   `_template/`: Contains structural templates (`literature.md`, `note.md`, `moc.md`).
*   `_AIOS/`: Contains system persona (`mi.md`) and AI mapping tools.
